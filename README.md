# DATA110 — Introduction to Data Analysis with R

Repository containing coursework, datasets, lecture materials, and statistical programming exercises completed throughout DATA110.

---

## Overview

This repository includes instructional materials and datasets used to learn foundational concepts in:

* Statistical analysis
* Data visualization
* Probability distributions
* Inferential statistics
* Data input and cleaning
* Programming in R

The course emphasizes practical data analysis using R and RStudio.
